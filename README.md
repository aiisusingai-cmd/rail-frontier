# 鉄路の果て

廃線を復旧し、資源を運び、鉄道網を守る2Dタワーディフェンスゲームです。

## 遊ぶ

https://aiisusingai-cmd.github.io/rail-frontier/

スマホは横画面がおすすめです。PCのブラウザでも遊べます。

- タップで駅を選択。ドラッグで地図を移動し、2本指で拡大・縮小。
- 「操作を開く」で建設・研究・車両管理を表示。「地図を広げる」で閉じます。
- 要塞は20・40・60・80・100・120駅で出現。6要塞奪還と150駅復旧でクリア。
- 開始操作で音声を再生。一時停止や画面を離れた間は無音になります。
- セーブは端末・ブラウザ内に保存されます。「やり直す」で塗装の解放状況も初期化されます。

## 配信

index.htmlにコード・画像を埋め込んだ静的ゲームです。追加のビルドやサーバー処理は不要です。
